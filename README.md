# 水下珞珈 · 沉没的武汉大学数字孪生

> An interactive, fully procedural WebGL scene of a sunken, submerged Wuhan University —
> Luojia Mountain, East Lake, and the campus landmarks, rendered as if resting at the bottom of the lake.

单文件（约 1600 行）纯前端 WebGL 场景，基于 [Three.js](https://threejs.org/) 构建。
**不依赖任何外部模型 / 贴图**——所有地形、建筑、植被、水面纹理全部代码程序化生成。
双击 `水下武汉大学.html` 即可在浏览器中打开漫游，唯一的联网依赖是首次加载 Three.js CDN 库。

## ✨ 特性

### 场景地理与校园建筑
- 高斯山体叠加 FBM 噪声还原**珞珈山**起伏，正弦 + 噪声弯曲岸线还原**东湖**湖床
- 程序化生成标志建筑：断裂的**武大牌坊**（"国立武汉大学"牌匾）、三级台地**老斋舍 + 樱顶**琉璃瓦亭、八角重檐**老图书馆**、**行政主楼**、绿穹顶**理学楼**、坍塌的**枫园湖滨教学楼**、**六一亭**
- 樱花大道、梧桐林荫道、山间百步梯、湖滨残破木栈道、民国式路灯

### 水下渲染
- 自定义片元着色器：湖水**光线焦散**、水体颜色随深度渐变（浅处清透湖绿 → 深处暗青墨蓝）
- **分层体积雾**：近景清晰，远景山体楼宇被湖水雾化衰减
- **沉积物覆盖层**：朝上表面按噪声积起淤泥藻膜，还原"久沉水底"质感
- 动态太阳光透过湖面形成晃动水下光影，建筑山体投射柔和阴影
- 粒子系统：发光浮游生物、缓慢下沉循环的落叶碎屑、顶点摆动的水草

### 写实渲染管线
- sRGB 输出 + **ACES Filmic 电影级色调映射**
- 程序化凹凸贴图（石材 / 树皮 / 墙面 / 路面表面起伏）
- FBM 噪声扰动的不规则有机树冠

### 交互
| 操作 | 功能 |
|------|------|
| `W` `A` `S` `D` | 前后左右移动 |
| `Space` | 上浮 |
| `Shift` | 快速下潜 |
| 鼠标拖拽 | 转动视角 |
| 滚轮 | 调节移动速度 |

带惯性的第一人称水下漫游控制器，含地形 / 湖面碰撞约束、视锥剔除 + 距离剔除优化。

## 🚀 运行

**本地**：直接双击 `水下武汉大学.html`，或用任意静态服务器：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/水下武汉大学.html
```

**在线演示**：仓库启用 GitHub Pages 后可直接访问（见仓库 Settings → Pages）。

## 🛠️ 技术栈

- Three.js r128（唯一外部依赖，CDN 引入）
- 原生 GLSL 着色器（`onBeforeCompile` 注入统一水下效果）
- Canvas 2D 程序化纹理生成
- 无构建步骤、无 npm 依赖、单 HTML 文件
